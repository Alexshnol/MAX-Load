MAX Load 4.2

גרסת PWA מלאה להעלאה לשורש מאגר GitHub Pages.

שינויים:
- שמירה אוטומטית של הסימולציה הפעילה.
- שחזור הסימולציה לאחר סגירת האפליקציה.
- 20 סימולציות אחרונות, מקוטלגות לפי תאריך ושעה.
- הסימולציה הפעילה אינה חלק מההיסטוריה.
- לחיצה על "סימולציה חדשה" מעבירה את הקודמת להיסטוריה.
- ללא כפתור שמירה וללא "מחק הכול".
- אפשרות לפתוח או למחוק סימולציה בודדת.

העלאה ל-GitHub:
יש להעלות את כל תוכן התיקייה לשורש המאגר, לא כתיקייה פנימית.
