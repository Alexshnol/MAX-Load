MAX Load 4.0
==============

פרסום ב-GitHub Pages:
1. העלה את כל הקבצים שבתיקייה זו לשורש המאגר MAX-Load.
2. ודא שב-Settings > Pages נבחר Deploy from a branch, branch main, folder /root.
3. פתח: https://alexshnol.github.io/MAX-Load/
4. בטלפון Android פתח ב-Chrome ולחץ על כפתור „התקנה” באפליקציה.
5. ב-iPhone פתח ב-Safari > שיתוף > הוסף למסך הבית.

חשוב: יש להעלות את כל הקבצים, כולל manifest.webmanifest, service-worker.js והאייקונים.

גרסה זו כוללת:
- PWA תקני עם מזהה, scope, start_url ואייקונים מסוג maskable.
- כפתור התקנה מובנה והנחיות ל-Android/iPhone.
- עבודה במצב לא מקוון לאחר פתיחה ראשונה.
- ניקוי אוטומטי של מטמון גרסאות קודמות.
- נתוני MAX Load 3.2 והמשאית IVECO מדיקל 67793404.
